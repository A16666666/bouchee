# Bouchée

Application web installable (PWA) de suivi des repas, calories et macros.

- Journal par repas, objectifs avec barres de progression
- Recherche et scan de codes-barres (Open Food Facts) + aliments de base intégrés
- Aliments, recettes et repas personnalisés
- Graphiques sur une période réglable
- Données stockées uniquement sur l'appareil (IndexedDB)

Installation sur iPhone : ouvrir https://a16666666.github.io/bouchee/ dans Safari → Partager → « Sur l'écran d'accueil ».

Développement : `npm install`, `npm run dev`, `npm run build`.
